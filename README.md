# COMP 4480 Intelligent & Autonomous Systems
## Description:
This is project for COMP 4480 class, in this class our objective is to create a program that is ready for Gazebo Simulation of Teknofest Fighter UAV Competition
## Current Abilities of the Project:
- PID Controller
- Fuzzy Controller
- Hybrid Controller
- Camera connection via OpenCV/Gstreamer
- UAV Detection with Yolo 11 (WIP)
- Ability to detect a UAV and take necessery maneuvers to follow it (WIP)
- Ability to dodge ADS sites using repulsion
- Ability to stay inside an predesignated quadrilateral area
- Ability to move towards the pre-given QR code's coordinates and make a dive to read it
